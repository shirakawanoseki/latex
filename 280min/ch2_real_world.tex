\section{2.17.1 Verbatim}

Use \verb|\LaTeX{}| to print \LaTeX.

We normally use \verb+|+ but 
when it's not available we
use \verb|+| to delimit the 
argument of the \verb|\verb|
commnad.

\verb*|\TeX user| will produce \TeX user.

To get proper spacing use \verb*|\TeX{} user.|

Several spaces are treated by \LaTeX{} as one space,
so \verb*|a    b| willl produce a     b.
