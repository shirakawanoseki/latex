Subscription in math mode are written as $a_b$ and superscription are written as $a^b$. Thesecan be
combined and nested to write expression such as

\[T^{i_1 i_2 \ddots i_p}_{j_1 j_2 \dots j_q} = T(x^{i_1},\dots,x^{i_p},e_{j_1},\dots, e_{j_q})\]

We write integral using $\int$ and fractions using $\frac{a}{b}$. Limits are placed on
integrals using superscriptions and subscriptios:

\[ \int_0^1 \frac{dx}{e^x} = \frac{e-q}{e}\]

Lower case Greek letters are written as $\omega$ $\delta$ etc. while upper case Greek
letters are written as $\Omega$ $\Delta$.

Mathematical operators are prefixed with a backslash as $\sin(\beta)$, $\cos(\alpha)$, $\log(x)$ etc.
